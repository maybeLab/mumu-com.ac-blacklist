# MuMu 按键精灵输入法修复：Windows 便携工具

这是一键工具测试版。用途是解除已确认的 MuMu 系统输入法黑名单，将 `com.ac/com.ime.input.InputKb` 设为默认并停用内置搜狗输入法。保留其他已启用的输入法，不会卸载搜狗应用。

## 已知问题：中文输入及远程控制

**2026-11-03 用户反馈：禁用原搜狗输入法后，模拟器内无法输入中文，UU 远程及 MuMu 模拟器 APP 远程控制中的中文输入、弹出输入法等功能也无法正常使用。当前工具仍会停用搜狗，此问题尚未修复。**

安装成功和“检查状态”读取完成不代表上述功能可用。此前的中文测试只覆盖按键精灵自身提交链路，没有覆盖本地手动输入或远程输入。需要这些功能的用户，应先评估此限制；已受影响时使用“恢复原设置.cmd”恢复首次安装前的配置，恢复后分别核对本地和两种远程输入。本次尚未执行这些场景的恢复后复测。

## 使用前

- Windows 10/11，系统自带 Windows PowerShell 5.1。请完整解压到有写入权限的文件夹，例如桌面，不要在压缩包内双击运行。
- 模拟器已 Root，安装并启用 KernelSU，允许 ADB shell 使用 Root。仅打开普通 Root 开关不一定具备 KernelSU 模块能力。
- 已安装包含按键精灵输入法的 `com.ac` 应用。
- 当前仅适配原排查实例的 MuMu 6.8.8.0、Android 15 / SDK 35、x86_64，且 `framework.jar` SHA-256 必须匹配：

  `5a46d36ebaf9b8088dc24b3601e7365123b6b258126ef4477fa6524b566fe349`

Root 不保证能附加系统进程；原实例 SELinux 为 Permissive。工具不会自动改变 SELinux。

## 三个双击入口

1. 启动 MuMu，在设置中开启 ADB。
2. 双击 **检查状态.cmd**，确认选择的是目标实例。
3. 双击 **安装.cmd**。需要时在模拟器内允许 Root 请求。工具检查兼容性、备份本设备原配置、安装模块，并立即应用。
4. 打开可输入文字的应用，确认默认输入法和按键精灵实际写入均正常。
5. 方便时手动重启模拟器，再次检查输入和状态。工具不会自动重启。
6. 要恢复时双击 **恢复原设置.cmd**。它恢复首次安装前的输入法设置并停用模块，保留备份。

工具优先使用旁边 `adb/adb.exe`、PATH、MuMu 常见安装目录或注册表中的 ADB，找不到时会让你填写 `adb.exe` 路径。本包没有捆绑 ADB，可以直接使用 MuMu 自带的 `shell/adb.exe`。

有多个在线实例时会显示列表让你选择。没有在线实例时需要输入该实例实际 ADB 地址，例如 `127.0.0.1:16384`；端口请以 MuMu 实例信息为准。不会扫描端口或自动选择其他实例。

高级用法（在 PowerShell 中执行，替换成自己的路径和端口）：

```powershell
.\安装.cmd -AdbPath "D:\MuMuPlayer-12.0\shell\adb.exe" -Serial 127.0.0.1:16384
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\repair.ps1 -Action Status -AdbPath "D:\MuMuPlayer-12.0\shell\adb.exe" -Serial 127.0.0.1:16384 -NonInteractive
```

`ExecutionPolicy Bypass` 仅用于本次进程，不更改系统持久执行策略；企业策略仍可能阻止运行。

## 备份与恢复

首次安装保存四项 secure 设置到 `/data/adb/mumu-ime-repair/original/`，权限受限，之后不会覆盖：

- `enabled_input_methods`
- `default_input_method`
- `selected_input_method_subtype`
- `input_methods_subtype_history`

恢复指的是**首次安装前**的配置。恢复后自行更改了输入法，再次安装仍保留第一次备份。不要随意删除或拷贝其他人的备份。恢复不会删除按键精灵、搜狗或其他应用。

在 KernelSU 中停用模块仅停止下次开机自动执行，当前内存修复要通过“恢复原设置”撤销，或重启清除。需要卸载时先成功恢复，再在 KernelSU 中卸载模块。模块 ID 为 `mumu_ime_allow_com_ac`，备份保留在模块目录以外。

曾使用旧版专用模块或一次性修复的用户，应先按旧项目文档恢复，再安装本工具。缺少本设备原备份且默认已是目标输入法、或检测到旧模块时，安装会停止，避免把已经修复的状态误当作原配置。请先在旧入口恢复，再在 KernelSU 中移除旧模块并重启；确认原配置已恢复后再安装。

## 失败时

- 找不到设备：检查 ADB 开关、实例端口和 ADB 授权，重新运行“检查状态”。
- 系统指纹不匹配：此包不适用，不要修改校验值强行安装；需要针对该版本重新排查。
- 未获得 Root / 找不到 KernelSU：先完成相应设置和 shell 授权。
- 缺少备份 / 备份不完整：保留目录与日志，先排查；工具不会猜测原配置。
- 应用失败或超时：安装可能已部分完成，先运行“检查状态”，保存工具旁边 `logs/` 中的日志。安装失败后已完成的备份或模块可能仍保留，不会自动反复重试。
- 更新 MuMu 后：校验会停止再次注入。可以恢复原输入法设置；如框架已变化，恢复脚本跳过旧版黑名单写回，并提示。

“检查状态”不上传脚本、不安装模块、不修改输入法；会读取 Root 状态、配置和模块日志。

## 原理、来源与验证范围

使用官方 Frida 16.7.19 Android x86_64 `frida-inject` 附加 `system_server`，移除已定位的输入法类名和证书黑名单项，再切换默认输入法。不修改系统 JAR 或应用 APK，不启动网络监听服务。开机服务重新应用内存修复；运行期间不监控 `system_server` 异常重启。

官方注入器来源：
https://github.com/frida/frida/releases/download/16.7.19/frida-inject-16.7.19-android-x86_64.xz

注入器 SHA-256：`d4cf923a40b5cd59eec8ae8025d7a473365342bbfa347d946d713d45ab32305e`

原设备已验证相同核心修复、中文提交和回退。**一键工具仅完成本地打包与模拟测试，尚未在真实模拟器安装；Windows 实机和重启自动执行仍未验证。** 包内 `package.json`、`SHA256SUMS.txt` 可核对内容完整性，它们不等同于数字签名。只从可信来源获取。

分享时发送整个 `MuMu-IME-Windows.zip` 即可，不要只发某个 CMD。分享模块给已有 KernelSU 的用户时发送 `mumu-ime-share.zip` 并附带本说明，在 KernelSU 管理器“模块”页从本地安装，完成后按需要重启或运行模块动作；恢复仍建议使用本工具或模块目录内的 `rollback.sh`。
